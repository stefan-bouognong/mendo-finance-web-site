# **App Name**: Mendo Finances

## Core Features:

- Hybrid Financial Landing: High-impact visual section highlighting the duality between physical microfinance and digital innovation with clear CTAs for account opening.
- Mendo COTI Digital Showcase: Interactive section showcasing the digital platform features like savings, tontine management, and transaction history using smartphone mockups.
- Financial Goal Assistant: An AI-powered tool that helps users calculate their tontine contributions and suggests savings strategies based on their financial goals.
- Live Activity Dashboard: Dynamic 'Chiffres Clés' component that visualizes transactions and account growth with animated counters.
- Integrated Social Hub: Embedded Facebook feed to display real-time updates and news without increasing asset weight, fetched via Graph API.
- Service Lead Management: Secure form submission system to collect account inquiries and contact requests for the governance team.

## Style Guidelines:

- Primary Color: Deep Royal Blue (#23395B) representing financial stability and authority.
- Background Color: A soft, off-white with a hint of the primary hue (#F5F7FA) for a clean professional look.
- Accent Color: Vibrant Cerulean (#00A8E8) used for buttons, interactive states, and emphasis to highlight the 'digital' aspect.
- Font Pairing: 'Space Grotesk' for headlines to emphasize modern technology, paired with 'Inter' for body text for maximum clarity and professionalism.
- Use Lucide-React for 'real' vector icons, focusing on clean strokes to represent banking, security, and community.
- Modern 'Card-based' layout with plenty of whitespace, using Tailwind's container system for a responsive, airy institutional feel.
- Smooth entrance animations using Framer Motion (fade-ups, stagger effects) to create a premium, agency-quality experience.
